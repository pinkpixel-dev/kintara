# Kintara

![Logo](./logo.png)

> “Obsidian meets Calibre meets Zotero meets VS Code Explorer… but prettier and faster.”

Kintara is a premium document organizer and reader application built with Tauri, React, and Vite. It offers a frictionless interaction with knowledge, prioritizing a distraction-free, highly polished dark/light UI.

## Features (In Development)
- **Library System**: Import PDFs, Markdown, and text files.
- **Organization**: Folders, tags, collections, favorites.
- **Reader Experience**: Smooth PDF and Markdown reading with split views and annotations.
- **Premium UI**: Monochromatic design with subtle accents.

## Development

```bash
npm install
npm run tauri dev
```
