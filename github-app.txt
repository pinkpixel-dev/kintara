When the prompt appears, paste the GitHub client secret and press Enter. The terminal will not display the pasted characters.

Set the other variables using Fish syntax too:
set --global --export KINTARA_PUBLIC_URL 'http://localhost:1420'
set --global --export KINTARA_GITHUB_CLIENT_ID 'paste-your-client-id-here'

Verify that all three variables exist without displaying the secret:

set --query KINTARA_PUBLIC_URL; and echo 'Public URL is set'
set --query KINTARA_GITHUB_CLIENT_ID; and echo 'Client ID is set'
set --query KINTARA_GITHUB_CLIENT_SECRET; and echo 'Client secret is set'

Then start Kintara from the same terminal:

npm run dev
